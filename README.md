# Python Day 85 - Find Duplicate Numbers

This program finds duplicate numbers from a Python list.

## Example

Input:
[10, 20, 30, 20, 40, 10, 50, 30]

Output:
Duplicate Numbers: [10, 20, 30]

## Concepts Used

- Lists
- for loop
- if condition
- count()
- append()
- not in
- Duplicate Values
